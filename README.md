# 色卡提取工具（ColorCard）

拿到概念图，点击导入，自动生成配色方案。支持色环调色、屏幕取色、导出 PNG 色卡。

## 解决的问题

概念设计阶段经常要从参考图里"扒"配色——截屏、取色、手动排色板，一套下来配色还没定，时间先没了。

这个工具可以导入参考图，自动提取代表色生成网格色卡。色环、饱和度/亮度滑块、笔刷模式都在一个窗口里，调好直接导出 PNG。

## 基本信息

| 项目 | 内容 |
| :--- | :--- |
| 运行环境 | Python 3.8+ |
| 界面框架 | tkinter + ttk（clam 主题） |
| 图像处理 | Pillow |
| 入口 | `python ColorCard.py` |

## 核心功能

### 🎨 色环选色

左上角色环实时 HSL 取色。拖拽手柄或点击色环切换色相，内圈显示当前饱和度/亮度下的完整色相环。手柄以当前颜色填充，黑白描边保证可读性。

### 🎚️ 饱和度 / 亮度

两个滑块分别控制饱和度和亮度（0~1），拖拽时色环实时刷新。基色数值显示在色环下方，点击直接复制 HEX 或 RGB。

### 🖌️ 笔刷模式

- **纯色绘制**：点击网格色块，用当前基色填充
- **随机色相**：保持饱和度/亮度不变，随机生成色相填充，制造色彩变体

### 📐 网格编辑

网格尺寸从 2×2 到 64×64 可选，切换后重置为空白画布。鼠标悬停高亮，自由点击填充。

### 📥 图片导入

支持多选图片同时导入，Pillow 量化算法自动提取代表色。颜色数量超出网格自动截断，不足以黑色补齐。

### 📊 排序算法

按 H-S-V 色环分桶排序，灰度色独立分组。每行内按人眼感知亮度从左到右排列——色卡过渡自然，不会东一块西一块。

### 🔍 屏幕取色

点击后主窗口隐藏，全屏半透明遮罩，冻结为静态截图。160×160 像素放大镜跟随鼠标，中心十字准星定位，底部显示坐标和色值。左键拾取，右键或 Esc 取消。多显示器下只高亮鼠标所在屏幕。

### 🔄 格式切换

点击「HEX/RGB」在两个格式间切换，影响基色数值显示和复制内容，色卡预览网格不受影响。

### 📌 置顶窗口

可按需开启窗口置顶，方便对照参考图或其他软件操作。

## 快速上手

1. 点「从图片导入」，选一张参考图（PNG / JPG / BMP，可多选）
2. 颜色自动提取并打散到网格
3. 拖拽饱和度和亮度滑块，或用色环选取基色
4. 点击网格色块用当前基色填充
5. 「打乱颜色」随机重排，「按色阶排序」恢复有序排列
6. 点「导出 PNG」保存色卡
7. 需要屏幕取色时点「屏幕取色」，冻结画面后用放大镜拾取

## 打包

双击 `自动打包工具.bat`，或把 `ColorCard.py` 拖到脚本上。脚本使用 PyInstaller 单文件模式生成 `ColorCard-Windows/ColorCard-portable.exe`，该 EXE 可直接发送给同事使用，不需要安装 Python。

## FAQ

**Q1：导入图片后色卡颜色感觉不对？**
Pillow 的 `quantize` 提取的是图中最具代表性的颜色，不是像素平均值。这个算法更符合人眼对色彩聚类的感知。

**Q2：排序后颜色还是乱的？**
排序按 H-S-V 色环分桶执行。如果网格里有些色块没填颜色（空白/白色），排序结果就不直观。确认有效颜色都到位后再排序。

**Q3：屏幕取色在某些软件上取不准？**
高 DPI 显示器下部分应用（尤其是游戏或全屏程序）可能因缩放导致坐标偏移。可以试试调整 Windows 显示缩放设置。
