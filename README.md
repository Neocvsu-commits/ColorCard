# 色卡提取工具（ColorCard）

## 1. 工具定位

从任意参考图中智能提取色彩并生成规范色卡的桌面工具。适合拿到概念图后快速建立配色方案，也支持直接拖出色板编辑和屏幕取色。

## 2. 基本信息

- 工具版本：正式版
- 运行环境：Python 3.8+
- 界面框架：tkinter + ttk（clam 主题）
- 图像处理：Pillow（PIL）
- 入口：`python ColorCard.py`

## 3. 标准使用流程

1. 点「从图片导入」，选择一张参考图（支持 PNG / JPG / BMP，可多选）
2. 工具自动提取色板，按人眼感知亮度排列到网格中
3. 拖拽调整饱和度和亮度滑块，或直接操作色环选取基色
4. 点击画布中的网格色块，用当前基色填充
5. 点「打乱颜色」随机重排，「按色阶排序」恢复有序排列
6. 点「保存色卡」导出为 PNG 图片
7. 需要取屏幕上某个颜色时，点「屏幕取色」，冻结画面后用放大镜精准拾取

## 4. 主要功能说明

### 4.1 色环选色
- 左上角色环提供实时 HSL 颜色选取
- 内圈显示当前饱和度与亮度下的色相环
- 拖拽色环手柄或直接点击色环切换色相
- 色环手柄以当前颜色填充，外围有黑/白色描边保证可读性

### 4.2 饱和度 / 亮度控制
- 两个滑块分别控制当前颜色饱和度（0~1）和亮度（0~1）
- 拖拽滑块时色环实时刷新当前参数下的色相环
- 基色数值显示在色环下方，点击即可复制 HEX 或 RGB 值

### 4.3 笔刷模式
- **纯色绘制**：点击网格色块时用当前选中的基色填充
- **随机色相**：保持当前饱和度/亮度不变，随机生成色相填充，制造色彩变体

### 4.4 网格编辑
- 网格尺寸可选 2×2 / 4×4 / 8×8 / 16×16 / 32×32 / 64×64
- 切换尺寸后网格重置为空白画布
- 鼠标悬停时高亮当前色块
- 支持自由点击填充各个色块

### 4.5 图片导入与色卡提取
- 支持多选图片同时导入
- 使用 Pillow 量化算法自动提取代表色
- 提取的颜色随机打散到网格中，可按需排序
- 颜色数量超出网格时自动截断，不足时以黑色补齐

### 4.6 排序算法
- 按 H-S-V 色环分桶排序
- 灰度色（低饱和度或低亮度）独立分组，不与彩色混淆
- 每行内按人眼感知亮度从左到右排列
- 看色卡时色彩过渡自然，不会东一块西一块

### 4.7 屏幕取色
- 点击后主窗口隐藏，全屏覆盖半透明遮罩
- 屏幕冻结为静态截图，不受窗口遮挡影响
- 160×160 像素放大镜跟随鼠标移动，中心十字准星精准定位
- 放大镜底部显示实时坐标与当前像素的色值
- 左键点击拾取，右键或 Esc 取消
- 多显示器环境下只高亮鼠标所在屏幕，其余屏幕保持遮罩

### 4.8 格式切换
- 点击「HEX/RGB」按钮在两种格式之间切换
- 影响：Base 数值显示、点击标签复制的内容
- 顶部色卡预览网格不受影响

### 4.9 置顶窗口
- 点击「置顶窗口」使工具始终位于其他窗口之上
- 方便对照参考图或其他软件时使用

## 7. 常见问题（FAQ）

### Q1：为什么导入图片后色卡看起来颜色不对？
工具使用 PIL 的 `quantize` 做色彩量化，提取的是图片中最具代表性的颜色，不是直接取像素平均值。这个算法更符合人眼对色彩聚类的感知。

### Q2：排序后颜色还是乱的？
排序按 H-S-V 色环分桶规则执行。如果色块本身没有填入颜色（空白/白色），排序结果就不直观。确认网格中已有有效颜色后再排序。

### Q3：屏幕取色在某些软件上取不准？
高 DPI 显示器下部分应用（尤其是游戏或全屏程序）可能因缩放导致坐标偏移。可以尝试调整 Windows 显示缩放设置。

### Q4：旧版 colorcard_DS 还需要维护吗？
不再维护。旧版保留仅供历史参考，功能已全部整合进 `ColorCard.py`。
